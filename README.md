🗑️ ડીલીટ થનાર ડેટા

  • Authentication સાથે જોડાયેલ મોબાઇલ નંબર તથા જી મેલ Google signup
  • Registration form માં ભરેલી તમામ માહિતી (નામ, હોદ્દો, સ્ટેશન વગેરે)
  • App માં save થયેલ duty entries
  • Generate થયેલ PDF reports નો record

────────────────────────────────────────

📋 રીકવેસ્ટ કઈ રીતે કરશો

  1. નીચે આપેલ WhatsApp અથવા Email દ્વારા અમારો સંપર્ક કરો
  2. તમારું Registered Mobile Number અને નામ જણાવો
  3. Verification પછી 30 દિવસની અંદર account સંપૂર્ણ delete કરવામાં આવશે
